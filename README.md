# Credit-Risk-Modeling-Lending-Strategy-Optimization
An end-to-end machine learning project aimed at improving bank credit-lending decisions using a more scientific, explainable, and data-driven approach.  The project integrates internal banking data with external bureau data to model multi-class credit risk aligned with the bank’s risk appetite.

Objectives
Understand different types of credit risk
Improve risk segmentation using ML
Build explainable models for business users

Project Workflow
Dataset integration (bureau + internal)
Data cleaning, outlier handling, and imputation
Exploratory Data Analysis
Feature engineering:
Chi-square tests
ANOVA
VIF and multicollinearity analysis
Model selection and hyperparameter tuning
Performance evaluation using appropriate loss metrics
Model deployment design
Feedback loop and retraining strategy

Tools & Techniques
Python
Machine Learning models
Statistical feature selection
Model explainability techniques

Key Outcomes
Improved, risk-aligned lending strategy
Transparent and explainable credit decisions
Feedback-driven model improvement framework
